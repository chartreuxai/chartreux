# Whole-TUI affordance evidence index

This index preserves the review baseline against commit `37abc9d` and the bounded after-repair comparison. PNG files are captures of the running TUI, not mockups. A screenshot proves visible presentation only; interaction, persistence, and mouse hit areas require separate Pilot or source evidence. The repeatable offline harness is [`capture_review.py`](capture_review.py); the [after capture README](evidence/after/README.md) gives a reproduction command and explains synthetic fixture and uncommitted-worktree limits. The frozen before manifest has 397 records, and the after manifest has 210 valid SVG/PNG pairs across 51 fixture states and 29 route labels.

Each seed stem below has four PNG variants under [`evidence/seed/`](evidence/seed/): `-80x24-textual-dark.png`, `-80x24-textual-light.png`, `-80x48-textual-dark.png`, and `-80x48-textual-light.png`. SVG companions are render artifacts; cite the PNG for visual findings. The route/fixture is the stem's named screen with offline fake state. Action sequence for these seed captures is route entry only; focused, dirty, error, and transition states need separate entries. Capture commit: `37abc9d`. The early `textual-*` export may have inherited `NO_COLOR`; **its palette names do not prove colored dark/light rendering**. Corrective `ansi-dark` captures, with effective terminal mode in the manifest, are the palette baseline for color claims. Mouse hit-area behavior is not established by screenshots.

## Coverage still required

The bounded 28-candidate remediation and after-capture matrix is complete, but the ten-family source ledger is wider than the 51 selected after states. Native terminal `NO_COLOR` contrast cannot be judged from the invalid no-color SVG export. Real external browser/OAuth and credential/proxy persistence outcomes, irreversible rewind commits, OS attachment opening, terminal pointer behavior outside Pilot, and untested route/state combinations still need separate evidence. The `provider-onboarding-model-detail` after fixture enters a synthetic in-memory stage, and `question-other-text` uses a standalone widget host; neither proves the full production transition. See the [after README](evidence/after/README.md) for these limits. A complete whole-TUI review still needs risk-based route/state, hit-area, and return-path coverage beyond this bounded finding set. Do not infer a behavior pass from a PNG matrix alone.
