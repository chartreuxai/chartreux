List all retained background agent instances and their current availability and run status. This is nonblocking and takes no arguments. The top-level `reuse_guidance` explains how to continue a retained instance with `task(agent_id=..., background=true, task=...)`; omit `agent_type` to retain its profile. Each entry's `agent_id` is an instance handle, while `profile` names its agent type. The `agent-N` syntax (digits after `agent-`) is reserved for instance handles, not profile names. Each entry includes its `profile`, `initial_task_summary`, `current_task_summary`, `effective_model`, `effective_thinking`, `idle_seconds`, and `ttl_remaining_seconds`; the TTL is advisory only and does not guarantee availability. `effective_thinking` is the semantic call-level/lower-layer choice, not provider wire-level encoding. Availability is `running`, `finalizing`, `idle`, or `evicted`. A `finalizing` agent has completed its run but is still committing its terminal result and cannot yet be reused. An evicted agent no longer has a runtime and cannot be reused, but preserves its last effective model/thinking and completed result may remain available through `get_agent_result` until result expiry.
