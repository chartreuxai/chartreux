List all retained background subagents and their current availability and run status. This is nonblocking and takes no arguments. Each entry includes its `profile`, `initial_task_summary`, `current_task_summary`, `effective_model`, `effective_thinking`, `idle_seconds`, and `ttl_remaining_seconds`; the TTL is advisory only and does not guarantee availability. `effective_thinking` is the semantic call-level/lower-layer choice, not provider wire-level encoding. Availability is `running`, `finalizing`, `idle`, or `evicted`. A `finalizing` agent has completed its run but is still committing its terminal result and cannot yet be reused. An evicted agent no longer has a runtime and cannot be reused, but preserves its last effective model/thinking and completed result may remain available through `get_agent_result` until result expiry.
