Wait for a background subagent run to complete. Supply `agent_id`, optionally `run_id` for a specific invocation, and optionally a positive `timeout` in seconds (default 1500; pass null to wait indefinitely). The result is a typed disposition, not a failure on timeout: `completed` carries the finished run's result, and `still_running` — returned when the timeout expires first — carries `agent_id`, `run_id`, `elapsed_seconds`, `run_status`, `turns_used`, and `guidance`. A timeout stops only this wait; it never cancels the background run. The `still_running` guidance instructs you to end your turn or continue other work now (queued user input is only delivered between turns) and to re-invoke `wait_for_agent` in a later turn to keep waiting; never re-invoke it in the same turn. Use `check_agents` to inspect progress. A `closed` or `evicted` agent cannot accept new work, but waiting on one returns its preserved result while it remains retained. A result-expired error means no result remains, and an unknown-agent or unknown-run error means the handle is invalid; use `check_agents` to inspect handles.
