Wait for a background subagent run to complete. Supply `agent_id`, optionally `run_id` for a specific invocation, and optionally a positive `timeout` in seconds. A timeout stops only this wait; it does not cancel the background run. An evicted agent cannot be reused, but waiting on one returns its preserved result while it remains retained. A result-expired error means no result remains, and an unknown-agent or unknown-run error means the handle is invalid; use `check_agents` to inspect retained handles.
