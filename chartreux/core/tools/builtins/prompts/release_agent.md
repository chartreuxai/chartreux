Release a background subagent and close its runtime. Supply `agent_id`. If the agent is still running, its current task is interrupted and any partial work is discarded. After release, the agent handle is invalid and retained run results are discarded — retrieve results before releasing. Releasing a `closed` or `evicted` agent is valid and removes its terminal metadata and results. Use release when an engagement concludes or an agent's work is no longer needed. This model-tool release is unguarded; the agent browser's release action is guarded and reports `conflict` when the agent is active, reserved for replacement, or pinned to a different latest run, and `unknown` when the handle is already released or its terminal metadata expired.
