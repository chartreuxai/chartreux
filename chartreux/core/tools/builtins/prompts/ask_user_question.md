Ask the user a question with structured options. Provide 1-4 questions, each with a header, question text, and 2-4 options. An "Other" free-text option is added automatically.

Unattended expiry (opt-in per question). Each question has a `kind` (`informational`, `preference`, or `requires_user`; the default `requires_user` never expires) and may declare an `unattended_default` (`action` is `defer_affected_work` or `preserve_existing_choice`, plus a plain-language `description`; `preserve_existing_choice` also names the existing `existing_choice` label to keep). A question without an `unattended_default` never expires, and any `requires_user` question blocks expiry for the whole batch. When every question is eligible and no answer arrives before the timeout, the question expires UNANSWERED: the affected work is deferred exactly as the declared default describes. Expiry never approves an option, never grants a permission, and never fabricates an answer — treat the unanswered result as "defer and continue", not as consent. Do not re-ask an expired question in a loop. The optional request-level `timeout_seconds` overrides the configured timeout and must fit the configured range; out-of-range values are rejected.
