Read a file. Use absolute paths. A read returns the whole file when it fits in one result; when the file is too large, the result carries the first chunk with its line range, a `next_offset`, and a `traversal_id` — continue by passing `offset` set to `next_offset` together with the same `traversal_id`, and repeat until the result reports no `next_offset` (end of file). The traversal restarts automatically if the file changes mid-read. Passing `offset`/`limit` explicitly reads exactly that bounded window and is never turned into a traversal. Results include a content `revision` identifying the file state that was read. Use `grep` to find specific content instead of reading sequentially. Do not read binary or model weight files (.bin, .safetensors, .pt, .gguf). Optionally set `outline: true` (off by default) to read the file's bounded symbol outline — classes, functions, and module-level bindings with line ranges, paired with the content `revision` — instead of its content; non-Python, unparsable, oversized, or sensitive-path files fall back to the normal read, and `outline: true` cannot be combined with `offset`, `limit`, or `traversal_id`.
