Search file contents with a regex. Returns matching file paths, line numbers, and lines, each with 2 lines of surrounding context by default (configurable via `[tools.grep] context_lines` and `default_max_matches`): matches use `path:line:content`, context lines use `path-line-content`, and disjoint regions are separated by `--`. `match_count` counts matches only, never context lines. Use `path` to narrow the search scope. When `files_only` is true (default OFF), the output instead lists the distinct matching file paths, sorted, one per line, capped at `max_matches` distinct files and `max_output_bytes`; `match_count` still counts matching lines.
