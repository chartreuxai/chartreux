Retrieve a completed background subagent result without waiting. Supply `agent_id` and, when retrieving a specific invocation, `run_id`; omitting `run_id` selects the latest run. A running run returns no result with a status message. An evicted agent cannot accept new work, but its completed results remain retrievable until expiry. A result-expired error means the result is no longer available; start a new agent for further work. An unknown-agent or unknown-run error means the handle is invalid; use `check_agents` to inspect retained handles.
