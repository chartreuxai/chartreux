Retrieve a completed background subagent result without waiting. Supply `agent_id` and, when retrieving a specific invocation, `run_id`; omitting `run_id` selects the latest run. A running run returns no result with a status message. A `closed` or `evicted` agent cannot accept new work, but its completed results remain retrievable until result expiry — terminal metadata expiring does not expire the result, while release purges results outright. A result-expired error means the result is no longer available; start a new agent for further work. An unknown-agent or unknown-run error means the handle is invalid (a released handle reports an unknown run); use `check_agents` to inspect handles.
