Submit externally verified tool-effect evidence for a suspended agent's reconcile barrier, pinning the submission to the failed run (`expected_run_id`) and its transcript boundary (`transcript_boundary`, from the failed run's failure envelope in `check_agents`). Supply one `verified_effects` entry per unknown tool call: `tool_call_id` with `disposition` `settled` (the effect completed consistently) or `unrepeatable_damage` (verification shows damage that cannot be undone or safely repeated), plus an optional bounded `note`. A run that left no tool call outstanding submits the empty list — the complete zero-entry accounting. An unverifiable outcome is simply not submitted — the barrier never auto-clears. Only the owning parent orchestrator may reconcile its background agents.

The result is a typed disposition: `cleared` (every verified effect settled; the barrier flips to eligible and `resume_agent` may proceed), `prohibited` (verification showed unrepeatable damage; the barrier flips to prohibited with reason codes and the agent can no longer be resumed — replacement via `task(agent_id=..., replace_run=True)` remains permitted), `stale` (the evidence is pinned to an earlier run or a different boundary and cannot clear a newer barrier), `duplicate` (the same run and boundary were already reconciled), `not_pending` (no reconcile barrier is pending for the agent), or `forbidden` (authority failure).
